# Apps bot examples

Минимальные polling-боты для проверки фреймворков в Apps.

| Фреймворк | Язык | `build_entry_path` | Переменная с токеном | Команда |
| --- | --- | --- | --- | --- |
| aiogram | Python | `aiogram` | `BOT_TOKEN` | `/start` |
| grammY | Node.js | `grammy` | `BOT_TOKEN` | `/start` |
| Telegraf | Node.js | `telegraf` | `BOT_TOKEN` | `/start` |
| telebot | Go | `telebot` | `BOT_TOKEN` | `/start` |
| VKBottle | Python | `vkbottle` | `VK_TOKEN` | `/start` |
| maxapi | Python | `maxapi` | `BOT_TOKEN` | `/start` |

## Настройки Apps

Для каждого примера:

1. Создайте backend App из этого репозитория.
2. Выберите соответствующие язык и фреймворк.
3. Укажите `build_entry_path` из таблицы.
4. Оставьте команды сборки и запуска по умолчанию.
5. Добавьте токен только в переменные окружения App.
6. Не добавляйте домен и HTTP health check.

Используйте отдельный тестовый токен для каждого одновременно работающего
App. При передеплое старый и новый polling-контейнеры могут некоторое время
использовать один токен, поэтому возможны конфликты и пропущенные ответы.
После удаления старого контейнера новый должен продолжить работу и снова
ответить на `/start`.

Токены нельзя сохранять в Git или выводить в диагностические логи.
